# 装修公司 ERP 落地项目作品

> 一个装修行业从业者，用系统把自己真实做了十几年的线下生意翻译成可运行的管理 SOP。
> 从报价到核算的最小业务闭环 —— 报价、合同、施工、收款、核算，一套系统到底。

这是一个 **求职作品集 / 开源演示项目**：把一家装修公司真实的线下业务流程，通过需求梳理、流程设计与规则固化，翻译成一套可直接跑通、数据可复算、私有化部署的业务系统。本项目以单文件静态页面形式呈现完整案例，可自由部署到任意静态托管（GitHub Pages / Vercel / 本地直接打开）。

---

## ✨ 项目亮点

| 维度 | 内容 |
|------|------|
| 业务闭环 | 报价 → 合同 → 施工 → 收款 → 核算，9 大环节全覆盖 |
| 核心规则 | 增项上限 8%、收款节点 3331、成本超支预警、应收逾期预警 |
| 双版本报价 | 客户版 + 内部谈判版，内部版实时算利润率，防止亏损签单 |
| 私有化部署 | 数据不出本机，规避云端 SaaS 数据安全与长期订阅成本 |
| 可校验性 | 演示数据可复算：付款节点 = 合同金额，逐笔可追溯 |

## 🚀 如何运行

**方式一：本地直接打开**
双击 `index.html` 即可在浏览器中查看完整案例，无需任何依赖。

**方式二：部署到 GitHub Pages**
1. 在 GitHub 新建仓库，将本项目所有文件推送到仓库
2. 进入仓库 `Settings → Pages`，Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后等待 1~2 分钟，即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问

> 提示：页面中的演示视频引用自外部 CDN，若需完全离线展示，可将视频文件放入 `assets/` 并修改 `index.html` 中 `<source>` 的 `src` 指向本地文件。

## 🧩 系统能力一览（9 大环节）

1. **项目建档** — 新建项目自动生成档案与编号（如 PRJ-2026-008）
2. **分项报价** — 选类目、填数量、改单价，金额自动计算
3. **报价单** — 含税/优惠/条款可配置，客户版 + 内部版双导出
4. **合同签订** — 一键生成收款节点，预警与催办自动生效
5. **施工管控** — 工序逐项勾验，不合格自动返工，增项确认后施工
6. **采购入库** — 成本自动归属工地与采购人，支持比价
7. **收款核销** — 3331 收款节点，逐笔核销结清
8. **回款台账** — 应收 − 已收 = 欠款，逐笔可追溯
9. **预警中心** — 缺预算 / 增项超限 / 成本超支 / 应收逾期自动预警

## 🎯 演示数据（可校验）

| 字段 | 值 |
|------|-----|
| 合同编号 | PRJ-2026-008 |
| 工程面积 | 450㎡ |
| 合同金额 | ¥102,563.00 |
| 付款节点 | 与合同金额逐笔相符（3331） |
| 增项上限 | 8%（¥8,205.04） |

一致性校验：付款节点合计 = 合同金额；增项未超上限；回款台账 = 应收 − 已收。
